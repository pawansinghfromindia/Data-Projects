# Databricks

A new platform to work with Big data with scalable system at the same time in most easy way.

> Databricks, understand how it is used in real companies from data analytics to data engineering for Data analysts, data engineers, Students
who are interested in modern data tools.

> Based on real industry workflows, simplified and explained using clear visuals, live demos, and practical examples.

**Who can learn Databricks?** <br/>
Data analysts, data engineers, BI professionals, career switch professionals and Students those who're interested modern data tools

**Data Engineers** vs **Data Analysts** 
1. Data Engineers (Work with Big data, Adv skills) 
2. Data Analysts (Analyze the data, SQL and at max PowerBI)

**Skills** 
1. Data Analysts : `Excelsheet`, `SQL`, `PowerBI` <br/>
2. Data Engineers : `SQL`, `Python`, `Pyspark`, `SparkSQL`
